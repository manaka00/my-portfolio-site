学校施設検索ナビ

HP

概要

自社で運営している学校施設をレンタルできるポータルサイトです。
全国の大学・専門学校の施設を、試験会場や講義スペースとしてレンタルできます。
また、施設をスペースとして貸し出すこともできます。

制作期間（担当期間）

2025年9月～現在に至る

担当範囲

設計 / 開発 / 運用 / 運営

業務内容

自社で運営するサイトの開発プロジェクトにおいて、一からのシステム開発に携わりました。
設計工程では、ユーザー同士がやり取りを行うメッセージ機能を担当し、誰が見ても理解しやすい設計を意識して作成しました。
リリース後は、既存ページやシステムの改修・運用保守、新規ページや機能の開発、SEOタグの設定などを担当しています。

自社サービスであるため、長期的な運用を見据えた開発が求められます。
システム部内では複数名が継続して開発・保守に携わっているため、ソースコードや引継ぎ資料は第三者でも理解しやすい記述を心がけました。
また、幅広いユーザーに利用されるサービスであることから、画面表示の細かな調整や、検索・ページ遷移時にエラーが発生しないよう品質を意識し、丁寧な開発・保守に取り組んでいます。

使用言語・ツール

言語： HTML / CSS / JavaScript / Ruby / Go
DB：MySQL
ツール：CMS(会社独自) / Visual Studio Code / NetBeans / XD
